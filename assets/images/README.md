# Fotografía del encabezado

Para completar el encabezado, añade una fotografía autorizada de campo colombiano con una persona y su cosecha en:

`assets/images/campesino-cosecha.jpg`

Se recomienda formato horizontal 4:3, luz natural y rostro ubicado hacia el lado derecho del encuadre. La imagen se recorta dentro de una máscara orgánica y recibe un degradado menta en el borde izquierdo. Usa una foto propia o con licencia y consentimiento adecuados.
